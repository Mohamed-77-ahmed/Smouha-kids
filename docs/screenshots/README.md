# Screenshots (Smouha Kids 1.2.0, versionCode 3)

Taken on 2026-10-17 on the test emulator Pixel_API_34_test (Android 14) from the installed debug build, by `scripts/screenshots.ps1` with the FICTIONAL demo data of `scripts/seed-demo.ps1` (Nour 7, Karim 15, Salma 40; no real patients). Arabic is set the way the app sets it (`ar-EG-u-nu-latn`, Western digits).

Names: `<screen>_<en|ar>_<light|dark>_font<10|15>.png` (font scale 1.0 or 1.5, normal phone 1080x2400 @420) and `home_size_<small|normal|tablet|unfolded>_<en|ar>.png` (480x800 @240, 1080x2400 @420, 1600x2560 @320, 2208x1840 @420; light, font 1.0). One overview per screen in `overview/`.

| Screen | What it shows |
|---|---|
| `home` | All patients, today's doses, the large confirm button |
| `add_patient` | Add medicine with no patient yet: the new patient fields (name, age, gender) |
| `pin_sheet` | The PIN sheet for confirming Nour's pill |
| `reward_child` | CHILD reward: cheering mascot, confetti, points (taken at the end of the count-up) |
| `reward_teen` | TEEN reward: badge, points, streak |
| `reward_adult` | ADULT reward: checkmark, points as text |
| `streak_broken` | CHILD streak ended: the mascot (sleepy, then happy; the frame shows the moment it was caught) |
| `about` | About: name, version, disclaimer, data stays on the phone |
