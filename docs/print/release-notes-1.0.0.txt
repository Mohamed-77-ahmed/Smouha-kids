Smouha Kids (Smouha University Children's Hospital)
Version 1.0.0, versionCode 1, 2026-10-18

First signed release for the families of the hospital's patients.
- Medicine reminders per child: every day or chosen days, one or more times, start and end dates.
- The alarm sound for up to 30 seconds at each reminder, also on silent or vibrate; up to 3 follow-ups.
- A parent PIN to confirm doses and to change medicines.
- Points, streaks and rewards by age group; points are never taken away.
- Egyptian Arabic and English. No internet, no account, no backup.

Important:
- A phone with an old test build of the app must uninstall it first (test data only).
- Later updates install over this version and keep all data.
- File check: SHA256.txt. Signing certificate SHA-256:
  FF:0A:9A:1B:D4:09:D3:85:03:76:FF:A2:C8:3D:0F:27:E2:39:4D:7B:2A:B7:3E:D6:9E:16:14:3E:FF:8A:E8:7A
- A reminder tool only; it gives no medical advice.
